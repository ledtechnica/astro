Design package

LED Technica — page designs

Seven pages, ready for an Astro port. Tailwind CSS with Catalyst-style component patterns, the three logo LEDs as functional accents (pink → infra/security, yellow → performance/postgres, cyan → cloud/api), Geist + Geist Mono throughout, and built-in light/dark/system mode.

Tap any card to open the page. Toggle the theme above — the choice persists across pages.

  • 01 · Home

    Article list with floating logo

    Glowing logo centered on load, morphs into the navbar on scroll. Featured post + 7 latest.
  • 02 · Post

    Single article

    Reading column, sticky TOC with scrollspy, syntax-highlighted code blocks, prev/next.
  • 03 · About

    About the author

    Sticky author card with stats, contact methods. Long-form bio on the right.
  • 04 · Archive

    Year-grouped archive

    Tag filter, year jump links, dense post-row layout. Per-tag pill color matches accent.
  • 05 · Search

    Full-text search

    ⌘K-style input, snippet results with highlighted matches, suggested tags.
  • 06 · Subscribe

    Subscribe / RSS hub

    Email digest hero, RSS / Atom / JSON Feed / Mastodon cards, per-tag feeds.
  • 07 · 404

    Page not found

    Three LEDs, middle one burnt out. Recovery links to home + search + popular posts.
